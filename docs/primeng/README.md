# Referências do PrimeNG para LLMs

Arquivos oficiais armazenados localmente para facilitar consultas durante a criação e manutenção dos componentes Angular/PrimeNG.

- `llms.txt`: índice resumido da documentação.
- `llms-full.txt`: documentação consolidada com exemplos e APIs dos componentes.

Fontes:

- https://primeng.dev/llms/llms.txt
- https://primeng.dev/llms/llms-full.txt

Para atualizar as cópias:

```bash
curl -fL https://primeng.dev/llms/llms.txt -o docs/primeng/llms.txt
curl -fL https://primeng.dev/llms/llms-full.txt -o docs/primeng/llms-full.txt
```
